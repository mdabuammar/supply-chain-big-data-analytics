## 🎯 Project Overview

This project demonstrates how **big data analytics** and **machine learning** can transform supply chain management by:

- **Reducing forecast error costs by 46.7%** (saving $2.28M annually)
- **Achieving 84.7% demand forecasting accuracy** using Random Forest
- **Identifying 91.2% of stockout risks** before they occur
- **Processing 91,250 transactions** across 50 SKUs, 5 warehouses, and 10 suppliers

### Problem Statement

Supply chain teams struggle with:
- Inaccurate demand forecasts leading to excess inventory or stockouts
- Inability to predict which products will run out of stock
- Limited visibility into seasonal patterns and regional variations

### Solution

A distributed big data pipeline using **Apache Spark** for data processing and **Random Forest** models for predictive analytics.
